# Combat draft (not in the game yet)

- `combat-mockup.js`: poses (wind up, strike, block, hurt, death), health bars and hitsplats for a hero vs goblin round. Needs `prototypes/goblin/goblin.js` loaded first, with `makeGoblin` exposed.
- `combat-sounds.py`: sword swing, hit, shield block, miss, male and female hurt, goblin attack, hurt and death. Run it to write WAV files.
- `combat-round.wav`: one full round in order.
- `preview.png`: the round frame by frame.
