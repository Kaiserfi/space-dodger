# Goblin prototype (not in the game yet)

`goblin.js` adds `makeGoblin(look)` and a small goblin camp by the woods (x -80, z 18), built on the game's own character model (`makeChibi`, `chibiPart`, `poseChibi`). Test it by pasting it into `adventure/index.html` right after `frame();` at the bottom of the script. `preview.png` shows how it looked.
